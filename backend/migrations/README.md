# SQL-миграции backend

Здесь находятся версии схемы PostgreSQL. Текущая пара файлов —
`000001_identity.up.sql` и `000001_identity.down.sql`. Она создаёт и удаляет
таблицы пользователей, компаний, членства и сессий.

Запуск из `backend` с настроенным DATABASE_URL:

```sh
go run ./cmd/migrate
```

Программа выполняет только `up`. Файлы `down` не запускаются автоматически.
Подготовка БД и описание таблиц — в [DATABASE.md](../../docs/DATABASE.md).
Правила новых версий, блокировки и восстановления после сбоя — в
[MIGRATIONS.md](../../docs/MIGRATIONS.md).
