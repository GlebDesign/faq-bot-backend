# FAQ Bot Backend

В репозитории размещается серверная часть FAQ-бота. Первый добавленный модуль — Python AI-прототип Ростика на LangChain.

- **[ai/README.md](ai/README.md)** — запуск, настройка моделей, команды и ограничения AI-прототипа.
- **[ai/ПРОВЕРКА.md](ai/ПРОВЕРКА.md)** — результаты проверок и границы готовности.

## Быстрый запуск в PowerShell

```powershell
cd ai
.\setup.ps1
.\run.ps1 demo
```

`setup.ps1` создаёт локальную `.venv` и устанавливает закреплённые зависимости. Повторный запуск допустим. Demo использует детерминированные заменители моделей и не требует Ollama. Для настоящих генерации и embeddings нужны выбранные командой модели и работающий Ollama — настройка описана в README модуля.

## Границы модулей

Ростик ведёт Python AI: обработку документов, RAG и проверку источников. Go API, авторизация аккаунтов и баланс — зона Дани. Инфраструктура — зона Сергея. Go-код в этом клоне пока отсутствует; его структура здесь не задаётся.

Текущий AI-модуль — локальный CLI. gRPC, RabbitMQ, pgvector, PDF/DOCX, история диалога и Coverage ещё не реализованы. Контракты интеграции нужно согласовать с Go-частью. Серверной авторизации в CLI нет, account/agent задаёт доверенный разработчик.

В репозиторий не включаются виртуальные окружения, локальные индексы, секреты, веса моделей и исходные клиентские документы.
